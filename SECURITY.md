# Política de Segurança -- GraceMap

## Versões Suportadas

| Versão | Suportada |
| ------ | --------- |
| 2.0.x  | sim       |

## Dados de Save

GraceMap lê arquivos de save do jogo. **Nunca** modifica saves sem permissão explícita do usuário. Backups são criados antes de qualquer operação destrutiva.

## Reportando

1. **Não** abra issue pública
2. Email ao mantenedor
3. Tempo: 48h recepção / 7d avaliação / 30d correção

## Escopo

- `src/`
- CI/CD
- Packaging (debian, flatpak)

## Fora do Escopo

- Bugs no jogo em si
- Estrutura do save file em patches futuros
